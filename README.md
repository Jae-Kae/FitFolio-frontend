# FitFolio – Frontend

FitFolio is a full-stack workout tracking application built with the MERN stack. This repository contains the **React frontend**, which connects to a custom backend API built with Node.js, Express, MongoDB, and Mongoose.

The goal of FitFolio was to build a clean, practical interface for tracking workouts and fitness progress, while gaining hands-on experience building and connecting a full-stack application end to end.

---

## Tech Stack

**Frontend**

- React
- JavaScript (ES6+)
- HTML5 / CSS3
- Fetch / REST API integration

**Backend (separate repo)**

- Node.js
- Express
- MongoDB
- Mongoose

---

## Features

- User-friendly interface for managing workout data
- Create, view, update, and delete workout entries
- Data persisted via a custom REST API
- Responsive UI built with reusable React components
- Clean separation between frontend and backend concerns

---

## Architecture Overview

- The React frontend handles UI, state management, and API requests
- The backend exposes RESTful endpoints for workout data
- MongoDB stores workout entries, modeled with Mongoose schemas
- The frontend communicates with the backend using HTTP requests

---

### Prerequisites

- Node.js (v14+ recommended)
- npm or yarn
- Backend server running locally or deployed

---

## Project Purpose

- This project was built to:

- Practice building a React frontend from scratch

- Learn how to connect a frontend to a custom backend API

- Work with MongoDB data through a Node/Express server

- Understand the data flow in a MERN application
